# 牌面素材（30 张 PNG）

| 项 | 说明 |
|---|---|
| 张数 | 30 张（万 1-9、筒 1-9、条 1-9、红中、发财、白板） |
| 尺寸 | 272 × 360 像素，竖版牌形 |
| 格式 | PNG（调色板模式，体积小，牌面白底 + 彩色字） |
| 来源 | 旧版素材（开源牌面库 zddd312/mahjong-tiles，MIT 许可） |

## 文件对照

| 文件名 | 牌 | raw 编码 |
|---|---|---|
| `Man1.png` … `Man9.png` | 一萬 … 九萬 | 0 – 8 |
| `Pin1.png` … `Pin9.png` | 一筒 … 九筒 | 9 – 17 |
| `Sou1.png` … `Sou9.png` | 一条 … 九条 | 18 – 26 |
| `Chun.png` | 红中 | 27 |
| `Fa.png` | 发财 | 28 |
| `Bai.png` | 白板 | 29 |

## 两种用法

1. **默认（推荐，走文件）**：`js/tileArt.js` 已经把 30 张图映射好了，UI 直接 `import { TILE_SRC }` 取图即可，路径用 `import.meta.url` 解析，页面放哪一层都不会断图。
2. **打成单文件 HTML**：`js/tileArt.base64.js` 是 30 张旧牌的内联版本，无外部请求，双击 HTML 也能显示牌面。
