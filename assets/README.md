# 牌面素材（28 张 PNG）

| 项 | 说明 |
|---|---|
| 张数 | 28 张（万 1-9、筒 1-9、条 1-9、红中） |
| 尺寸 | 272 × 360 像素，竖版牌形 |
| 格式 | PNG（调色板模式，体积小，牌面白底 + 彩色字） |
| 总量 | 174 KB |
| 来源 | 开源牌面库 zddd312/mahjong-tiles（MIT 许可），与原线上版本同一套图 |

## 文件对照

| 文件名 | 牌 | raw 编码 |
|---|---|---|
| `Man1.png` … `Man9.png` | 一萬 … 九萬 | 0 – 8 |
| `Pin1.png` … `Pin9.png` | 一筒 … 九筒 | 9 – 17 |
| `Sou1.png` … `Sou9.png` | 一条 … 九条 | 18 – 26 |
| `Chun.png` | 红中 | 27 |

## 两种用法

1. **默认（推荐，走文件）**：`js/tileArt.js` 已经把 28 张图映射好了，UI 直接 `import { TILE_SRC }` 取图即可，路径用 `import.meta.url` 解析，页面放哪一层都不会断图。
2. **打成单文件 HTML**：把 `js/tileArt.js` 换成 `js/tileArt.base64.js`（原版 233KB base64，无任何外部请求，双击 HTML 也能显示牌面）。

## 不含的东西

- **牌背**：原工程牌背是 CSS 画的（绿色斜面带高光），不在这批 PNG 里。新 UI 想用图片牌背，需要自己出一张 `back.png`。
- **桌布 / 木框 / 桌面纹理**：同样是 CSS 画的，属于界面，不在素材里。
- **牌面小字提示（听牌角标等）**：属于 UI 叠加元素。

换牌面只要覆盖同名 PNG（保持尺寸比例一致），代码不用动。
