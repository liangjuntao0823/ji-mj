# 牌面素材（30 张 PNG）

| 项 | 说明 |
|---|---|
| 张数 | 30 张（万 1-9、筒 1-9、条 1-9、红中、发财、白板） |
| 尺寸 | 300 × 400 像素，竖版牌形 |
| 格式 | PNG（RGBA 透明底，牌面白底 + 彩色字，圆角外透明） |
| 总量 | 约 888 KB |
| 来源 | 用户提供的「港式加深加粗」素材，已做圆角外白底透明和缩放 |

## 文件对照

| 文件名 | 牌 | raw 编码 |
|---|---|---|
| `Man1.png` … `Man9.png` | 一萬 … 九萬 | 0 – 8 |
| `Pin1.png` … `Pin9.png` | 一筒 … 九筒 | 9 – 17 |
| `Sou1.png` … `Sou9.png` | 一条 … 九条 | 18 – 26 |
| `Chun.png` | 红中 | 27 |
| `Fa.png` | 发财 | 28 |
| `Bai.png` | 白板 | 29 |

## 两种用法

1. **默认（推荐，走文件）**：`js/tileArt.js` 已经把 30 张图映射好了，UI 直接 `import { TILE_SRC }` 取图即可，路径用 `import.meta.url` 解析，页面放哪一层都不会断图。
2. **打成单文件 HTML**：把 `js/tileArt.js` 换成 `js/tileArt.base64.js`（v1.2.1 约 1.1MB base64，无任何外部请求，双击 HTML 也能显示牌面）。

## 不含的东西

- **牌背**：原工程牌背是 CSS 画的（绿色斜面带高光），不在这批 PNG 里。新 UI 想用图片牌背，需要自己出一张 `back.png`。
- **桌布 / 木框 / 桌面纹理**：同样是 CSS 画的，属于界面，不在素材里。
- **牌面小字提示（听牌角标等）**：属于 UI 叠加元素。

换牌面只要覆盖同名 PNG（保持尺寸比例一致），代码不用动。
