# 监利红中 · 横屏版（UI 成品包）

在原「逻辑核心包」之上加了一整套横屏麻将手游界面：首页、牌桌、牌河、副露、动作区、联机大厅、结算、记分板、规则弹窗。
**引擎、规则、算分、联机、重连一行未改**，包内功能全部保留。

## 0. 在线版

- 网址：<https://jianli-majiang.pages.dev/?v=107>
- 备用（手机网络打不开 pages.dev 时）：<https://liangjuntao0823.github.io/ji-mj/?v=107>
- 仓库：<https://github.com/liangjuntao0823/ji-mj>（公开）
- Cloudflare Pages：项目 `jianli-majiang` 为 Direct Upload（拖拽上传 `index.html` 发布），不接 Git 自动构建；源码与单文件成品在 `ji-mj`，每次改版先推仓库，再把 `监利红中-横屏版.html` 复制为 `index.html` 上传到该项目。
- 在线版支持单机、手机 P2P 建房/加入；局域网模式需要本机跑 `server.js`（Pages 只托管静态页面，不跑 Node）。

## 1. 两种跑法

| 想干嘛 | 怎么做 | 需要什么 |
|---|---|---|
| 直接玩单机 / 手机 P2P 建房 | 双击 `监利红中-横屏版.html` | 一个浏览器（Chrome / Edge / Safari 都行），无需联网、无需服务器 |
| 同一 WiFi 四台手机联机 | 双击 `启动局域网.bat`（或 `node server.js`），手机打开命令行里给出的网址 | 一台开着的电脑 + Node |

> 单文件版是**整包自包含**：CSS、全部脚本、28 张牌面、4 个头像、PeerJS 全部内联，没有任何外部请求。
> 局域网联机必须有服务端（浏览器之间无法直接开 HTTP 服务），所以走文件夹版 + `server.js`。

默认端口 8878，可用 `set PORT=9000` 改。

## 3. 界面里有什么

- **首页**：主题标题 + 4 张牌面展示 + 三个模式入口（单机 / 联机房间 / 手机建房）+ 规则、声音、全屏。
- **牌桌**：四家座位牌板（头像环、风向、庄标、分数、思考中、30 秒计时胶囊）、牌背墙、露牌区（碰、明杠、暗杠、回头笑，侧家露牌随座位转 90°，打出的红中按张摆在露牌区）、四向牌河、桌心风盘（四个方向箭头指着当前出牌的人并闪烁，圈心大字倒计时，杠的盖牌收在圈心）、手牌（摸牌抬高、选中态、锁定态）、动作区（吃碰杠胡过 + 报听）、右下角听牌提示（听哪几张、每张还剩几张；轮到出牌时按你选中的那张实时算「打 X 听」）、提示条。
- **结算**：番型明细、倍数、本局各家 ±份（油公式 `(1+赢家红中)×(1+自家红中)`）、本局得分 + 累计总分；赢家框金框高亮。整场结束出总排名（含「胡 X 局 / 总 Y 番」），所有真人齐点「再来一场」才重开。
- **记分板**：累计总分 / 胡局 / 总番一览。
- **规则弹窗**、**掉线暂停遮罩**、**竖屏旋转提示**、**音效开关**（WebAudio 合成，无音频文件依赖）。

**只做横屏**：按横屏比例铺满视口，宽屏自动扩展牌桌填满左右空间；手机竖屏锁定状态会自动把页面旋转成横屏。

**版本号**：首页显示 `v1.0.0`；每次发版同步更新 `js/version.js`、首页徽章、`CHANGELOG.md` 和「更新记录」弹窗。

## 3.1 联机与断线重连规则

**局域网（同一 WiFi，`node server.js` 起服务，四人打开同一网址）**

- 名字必填；第一个进房的是房主（东家）。不满 4 人开局，空位自动补机器人。
- 12 秒没有心跳判掉线：全场暂停 → 倒计时冻结、机器人停手、弹「XX 掉线，等待重连」并自动打开记分板。
- 重连：**同一个名字**再点「加入」就回原座位（手牌、分数原样）；刷新页面会用本地 token 自动回座。
- 有人掉线期间，出牌 / 碰杠 / 下一局请求都会被服务端拒绝，不会替掉线的人代打。
- 每局打完四人齐点「下一局」；第 8 局结束直接出总排名，所有真人都点「再来一场」才开新一场，分数清零。

**手机 P2P（跨省，WebRTC 直连，房主建房出 6 位房号）**

- 朋友填「名字 + 房号」加入；开局中陌生人进来会被拒（等这局打完）。
- 直连优先；跨省 / 对称 NAT 直连不成会自动走 Cloudflare TURN 中继（页面实时换取短期凭证，过期自动重取）。
- 3 秒一次心跳、10 秒没回包判掉线：全场暂停 + 提示 + 自动打开记分板；掉线方重新用**同一个名字 + 同一个房号**进房就回原座，手牌原样继续。
- 房主是权威端，算牌、超时代打、结算都在房主这边；客人只发操作、收快照。
- 打满 8 局直接出总排名；所有真人（不含机器人）齐点「再来一场」才重开。

## 4. 操作

- 出牌：点一张手牌 → 再点一次打出（只能打该打的牌，红中/报听后会自动限制）。
- 碰杠胡：右下动作区按钮；有多个杠可选时弹选牌面板。
- 报听：动作区「报听」；之后只能打仍听牌的牌，摸到不听牌自动打出。
- 换局：四人齐点「下一局」；整场 8 局打完出排名，齐点「再来一场」重开。

## 5. 已知边界

- 单文件版里联机入口仍需服务端（局域网和 P2P 都是），只有单机对局可离线双击开打。
- P2P 依赖 PeerJS 公共云信令（`0.peerjs.com`），断网不可用；同 WiFi 更推荐局域网模式。
- 牌面图沿用包内素材（272×360 PNG），未重绘。
